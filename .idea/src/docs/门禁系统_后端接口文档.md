## 2. API 接口设计

### 2.1 用户注册

**接口**: `POST /api/v1/users/register`

**功能**: 将新用户的人脸+指纹注册到 Gallery

**请求**:
```json
{
  "user_id": "001",
  "face_image": "base64编码或文件路径",
  "fingerprint_image": "base64编码或文件路径"
}
```

**响应**:
```json
{
  "success": true,
  "user_id": "001",
  "message": "注册成功",
  "gallery_updated": true
}
```

**处理流程**:
1. 接收前端上传的图片
2. 使用人脸/指纹模型提取特征向量
3. 将特征向量存储到 Gallery 数据库
4. 返回注册结果

---

### 2.2 用户识别

**接口**: `POST /api/v1/recognize/fusion`

**功能**: 根据人脸和/或指纹图片识别用户身份。支持只人脸、只指纹、人脸+指纹三种模式。

**请求**:
```json
{
  "face_image": "base64编码",
  "fingerprint_image": "base64编码",
  "top_k": 5,
  "fusion_weight_face": 0.5,
  "fusion_weight_fp": 0.5
}
```
> 至少提供一个模态图片。只提供一个时自动降级为单模态识别。

**响应**:
```json
{
  "success": true,
  "matched": true,
  "user_id": "001",
  "name": "张三",
  "face_image": "base64编码（注册时的人脸图片）",
  "candidates": [
    {"user_id": "001", "rank": 1},
    {"user_id": "042", "rank": 2},
    {"user_id": "128", "rank": 3}
  ],
  "modality": "fusion",
  "fusion_method": "adaptive"
}
```

> `matched: true` 表示识别到用户。`candidates` 按排序返回，rank=1 为最佳匹配。置信度分数已被移除，因为余弦相似度不具备统计意义，不能反映正确率。

---

### 2.5 用户管理

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/v1/users` | GET | 获取所有已注册用户列表 |
| `/api/v1/users/{user_id}` | GET | 获取指定用户信息 |
| `/api/v1/users/{user_id}` | DELETE | 删除指定用户（从 Gallery 移除）|
| `/api/v1/users/count` | GET | 获取已注册用户数量 |

## 4. 模型加载与推理

### 4.1 模型文件结构

```
checkpoints/
├── fusion/
│   ├── best_concatfusion.pth      # 最佳融合模型
│   ├── best_gatedfusion.pth       # 门控融合模型
│   └── best_attentionfusion.pth   # 注意力融合模型
└── gallery/
    └── face_features.json         # Gallery 特征库
```

### 4.2 推理流程

```
1. 加载预训练模型 (best_*.pth)
2. 加载 Gallery 特征库 (features.json)
3. 接收前端图片
4. 图片预处理 (resize, normalize)
5. 特征提取 (人脸模型 / 指纹模型)
6. 特征匹配 (余弦相似度)
7. 返回 Top-K 结果
```

## 6. 对接 Unity 前端

### 6.1 Unity 发送请求示例

```csharp
// Unity C# 代码示例
using UnityEngine;
using System.Collections.Generic;

public class ApiClient : MonoBehaviour
{
    private string baseUrl = "http://localhost:8000/api/v1";

    // 上传新用户
    public IEnumerator RegisterUser(string userId, byte[] faceImage, byte[] fpImage)
    {
        // 转换图片为 Base64
        string faceBase64 = Convert.ToBase64String(faceImage);
        string fpBase64 = Convert.ToBase64String(fpImage);

        string json = JsonUtility.ToJson(new RegisterRequest {
            user_id = userId,
            face_image = faceBase64,
            fingerprint_image = fpBase64
        });

        // 发送 POST 请求
        // ...
    }

    // 人脸识别
    public IEnumerator RecognizeFace(byte[] faceImage)
    {
        string faceBase64 = Convert.ToBase64String(faceImage);
        string json = JsonUtility.ToJson(new RecognizeRequest {
            face_image = faceBase64
        });

        // 发送 POST 请求
        // ...
    }
}
```

### 6.2 响应处理

```csharp
[System.Serializable]
public class RecognizeResponse
{
    public bool success;
    public bool matched;
    public string user_id;
    public string name;
    public string face_image;  // 注册时的人脸图片 Base64
    public List<Candidate> candidates;
    public string modality;
}

[System.Serializable]
public class Candidate
{
    public string user_id;
    public int rank;
}
```

> Unity 中使用 `JsonUtility.FromJson` 反序列化时需注意字段顺序，建议从 `success` 开始按声明顺序排列。
