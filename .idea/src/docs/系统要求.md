# 门禁系统 - 系统要求

本文档定义了运行门禁系统后端推理服务所需的硬件、软件及网络环境要求。Unity 项目可在启动时或设置页面调用 `check_requirements.py` 脚本检测运行环境是否满足条件。

---

## 1. 硬件要求

### 1.1 最低配置（CPU 推理）

| 项目 | 要求 |
|------|------|
| CPU | Intel Core i5 第 8 代 / AMD Ryzen 5 2600 及以上 |
| 内存 | 8 GB RAM |
| 存储 | 10 GB 可用空间（不含数据集） |
| 网络 | 千兆以太网（后端与 Unity 通信） |

### 1.2 推荐配置（GPU 推理）

| 项目 | 要求 |
|------|------|
| GPU | NVIDIA GPU，显存 ≥ 6 GB（如 GTX 1660 Super / RTX 3060） |
| CPU | Intel Core i7 第 10 代 / AMD Ryzen 7 3700X 及以上 |
| 内存 | 16 GB RAM |
| 存储 | 20 GB SSD 可用空间（不含数据集） |

> 注：GPU 推理速度约为 CPU 的 10-20 倍，推荐在生产环境中使用 GPU 推理。

### 1.3 Unity 端要求

| 项目 | 要求 |
|------|------|
| Unity 版本 | 2021.3 LTS 及以上 |
| .NET 版本 | .NET Standard 2.1 / .NET Framework 4.8 |
| 网络 | 可访问后端服务地址（HTTP） |

## 3. 模型文件要求

### 3.1 模型文件列表

推理服务启动前需确认以下模型文件存在：

| 模型文件 | 路径 | 说明 |
|----------|------|------|
| 融合模型（simple） | `checkpoints/fusion/*/best_simple.pth` | 加权融合模型 |
| 融合模型（gated） | `checkpoints/fusion/*/best_gated.pth` | 门控融合模型 |
| 融合模型（adaptive） | `checkpoints/fusion/*/best_adaptive.pth` | 注意力融合模型 |
| 人脸预训练权重 | `checkpoints/face/*.pth` | 人脸单模态模型（可选） |
| 指纹预训练权重 | `checkpoints/fingerprint/*.pth` | 指纹单模态模型（可选） |

> 模型文件由训练阶段生成，首次运行前需执行训练脚本（参见 `train_fusion.py`）。

### 3.2 模型加载说明

- 推理服务启动时使用 `--model` 参数指定模型文件路径
- 支持加载多个融合模型，运行时按需切换
- 模型文件损坏时，服务启动失败并输出错误信息

## 6. Unity 端集成说明

### 6.1 调用检测脚本（C# 示例）

Unity 可通过子进程调用 `check_requirements.py`，解析返回的 JSON 结果：

```csharp
using System.Diagnostics;
using System.Text;
using UnityEngine;
using System.Threading.Tasks;

public class RequirementsChecker : MonoBehaviour
{
    private const string PythonPath = "python";
    private const string ScriptPath = "scripts/check_requirements.py";

    public async Task<RequirementsResult> CheckRequirements()
    {
        var psi = new ProcessStartInfo
        {
            FileName = PythonPath,
            Arguments = $"\"{ScriptPath}\" --format json",
            RedirectStandardOutput = true,
            RedirectStandardError = true,
            UseShellExecute = false,
            CreateNoWindow = true
        };

        var process = Process.Start(psi);
        string output = await process.StandardOutput.ReadToEndAsync();
        string error = await process.StandardError.ReadToEndAsync();
        await process.WaitForExitAsync();

        if (process.ExitCode != 0)
        {
            Debug.LogError($"Requirements check failed: {error}");
            return null;
        }

        // 解析 JSON 并展示结果
        return JsonUtility.FromJson<RequirementsResult>(output);
    }
}

[System.Serializable]
public class RequirementsResult
{
    public string overall;       // "pass", "warn", "fail"
    public CheckItems checks;
}

[System.Serializable]
public class CheckItems
{
    public CheckItem python_version;
    public CheckItem torch_version;
    public CheckItem cuda_available;
    public CheckItem model_files;
    public CheckItem gallery_path;
    public CheckItem backend_connectivity;
}

[System.Serializable]
public class CheckItem
{
    public string status;        // "pass", "warn", "fail"
    public string detail;        // 详细说明
}
```

### 6.2 启动时自动检测

建议在 Unity 启动场景中增加一个设置页面，在用户进入主界面之前：

1. 调用 `check_requirements.py`
2. 根据 `overall` 结果显示提示：
   - `pass` — 绿色提示"环境检测通过"
   - `warn` — 黄色提示"部分项目不满足要求，功能可能受限"
   - `fail` — 红色提示"环境不满足要求，请检查后端配置"

## 7. 快速检测脚本

程序化检测请参见 `scripts/check_requirements.py`。

用法：

```bash
# 完整检测（默认）
python scripts/check_requirements.py

# 指定格式输出
python scripts/check_requirements.py --format json    # 结构化 JSON（推荐）
python scripts/check_requirements.py --format text   # 人类可读文本

# 按模块检测
python scripts/check_requirements.py --check python
python scripts/check_requirements.py --check torch
python scripts/check_requirements.py --check cuda
python scripts/check_requirements.py --check models
python scripts/check_requirements.py --check gallery
python scripts/check_requirements.py --check network

# Unity 集成示例
python scripts/check_requirements.py --format json --check all
```

## 8. 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| `torch.cuda.is_available()` 返回 `False` | 未安装 GPU 版 PyTorch 或驱动问题 | 重新安装 `torch+cu118` / `torch+cu121` |
| 模型文件未找到 | 训练未完成或路径配置错误 | 检查 `checkpoints/` 目录 |
| 端口被占用 | 8000 端口被其他程序占用 | 修改 `config.py` 中的 `port` 配置 |
| Gallery 为空 | 尚未注册用户 | 调用注册 API 先注册用户 |
| Unity 请求超时 | 网络延迟或 GPU 推理过慢 | 调大 Unity 端超时时间，或切换至 GPU 推理 |
| `ModuleNotFoundError` | 依赖包未安装 | 运行 `pip install -r requirements.txt` |
