## 一、项目概述

本次毕设的研究目标是：**基于人脸与指纹的多模态生物特征融合识别**。

单一生物特征存在天然局限：人脸受光照、遮挡、角度影响较大；指纹则依赖接触，对干湿、磨损敏感。将两者在特征层面进行融合，可以实现互补，显著提升识别系统在复杂环境下的鲁棒性和准确率。

整个系统分为两大部分：
- **训练阶段**：分别训练人脸和指纹单模态模型，再训练融合模型
- **推理阶段**：用户通过 API 提交人脸和/或指纹图片，系统提取融合特征，与底库进行 1:N 余弦相似度检索，返回识别结果

### 3.1 FaceNet 架构

**文件位置**：`core/models/face_net.py`

人脸模型采用经典的 **ResNet50 + 双注意力 + ArcFace** 架构。

```startLine:10:199:core/models/face_net.py
class FaceNet(nn.Module):
    def __init__(self, num_classes=100, embedding_dim=512, pretrained=True,
                 dropout_rate=0.5, spatial_attention=True):
        super(FaceNet, self).__init__()
        self.backbone = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V1)
        self.backbone.fc = nn.Identity()

        self.spatial_attn = SpatialAttention(self.backbone_out_channels, reduction_ratio=16)
        self.global_pool = nn.AdaptiveAvgPool2d((1, 1))

        self.feature_projection = nn.Sequential(
            nn.Linear(self.backbone_out_channels, embedding_dim),
            nn.BatchNorm1d(embedding_dim),
            nn.Dropout(dropout_rate)
        )

        self.attention = nn.Sequential(
            nn.Linear(embedding_dim, embedding_dim // 4),
            nn.ReLU(inplace=True),
            nn.Linear(embedding_dim // 4, embedding_dim),
            nn.Sigmoid()
        )
```

流程：图像 → ResNet50 主干 → 空间注意力增强局部特征 → 全局池化 → 512 维投影 → **通道注意力**重加权 → L2 归一化输出 512-d 嵌入向量。

训练脚本位于 `scripts/train_face.py`，使用 ArcFace metric learning，scale=30，margin=0.5，学习率 3e-5，配合随机裁剪、水平翻转、RandomErasing 等数据增强。

> 这部分代码结构清晰，是标准的 metric learning 训练流程，答辩时一笔带过即可。

## 五、模块二：融合模型（重点）

这是本毕设的核心创新点。

### 5.1 融合模型整体结构

**文件位置**：`core/models/fusion_model.py`

融合模型由三个组件串联构成：

```
人脸特征(512-d) ──→ [模态投影层] ──→ (256-d)
                                          │
指纹特征(512-d) ──→ [模态投影层] ──→ (256-d)
                                          │
                                    [融合策略] ← 可插拔
                                          │
                                    Dropout(0.3)
                                          │
                                   ArcFace 分类头(256-d → num_classes)
```

**第一组件：模态投影层** `ModalityProjection`

```startLine:27:57:core/models/fusion_model.py
class ModalityProjection(nn.Module):
    def __init__(self, input_dim, output_dim):
        super().__init__()
        self.projection = nn.Sequential(
            nn.Linear(input_dim, output_dim),
            nn.LayerNorm(output_dim),
            nn.GELU(),
        )
        self._init_as_identity(input_dim, output_dim)

    def _init_as_identity(self, input_dim, output_dim):
        linear = self.projection[0]
        with torch.no_grad():
            if input_dim == output_dim:
                linear.weight.copy_(torch.eye(output_dim))
            else:
                min_d = min(input_dim, output_dim)
                weight = torch.zeros_like(linear.weight)
                weight[:min_d, :min_d] = torch.eye(min_d)
                linear.weight.copy_(weight)
            linear.bias.zero_()
```

**关键设计**：投影层权重初始化为**恒等映射**（或部分恒等）。这意味着训练开始时，两个模态的特征直接原样传递到融合层，融合层从"平等对待两个模态"的起点开始学习，而不是从随机状态开始。这保证了训练的稳定性。

投影将 512 维压缩到 256 维，迫使信息融合必须发生——两个模态必须互相补充才能保留关键信息。

**第三组件：ArcFace 分类头**


### 5.2 两种融合策略

**文件位置**：`core/models/fusion_strategy.py`

融合策略采用**插件式设计**，通过工厂函数创建不同的策略实例。

#### 策略一：简单加权融合（WeightedSumStrategy）

```startLine:38:55:core/models/fusion_strategy.py
class WeightedSumStrategy(FusionStrategy):
    def __init__(self, fusion_dim: int):
        super().__init__()
        self.weight = torch.tensor([0.5, 0.5])

    def forward(self, face_feat, fp_feat):
        w = F.softmax(self.weight, dim=0)
        return w[0] * face_feat + w[1] * fp_feat
```

最简单的方式：两个可学习权重经过 softmax 后做加权求和。初始化为 0.5/0.5，即两个模态平等对待。

#### 策略二：注意力自适应融合（AttentionStrategy）—— 重点

这是本毕设提出的核心融合方法。

```startLine:58:120:core/models/fusion_strategy.py
class AttentionStrategy(FusionStrategy):
    def __init__(self, fusion_dim: int, hidden_dim: int = 64):
        super().__init__()
        self.attention = nn.Sequential(
            nn.Linear(fusion_dim * 2 + 1, hidden_dim),
            nn.LayerNorm(hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.1),
            nn.Linear(hidden_dim, 2),
        )
        nn.init.zeros_(self.attention[-1].weight)
        nn.init.zeros_(self.attention[-1].bias)
        self.logits_bias = nn.Parameter(torch.zeros(2))

    def forward(self, face_feat, fp_feat):
        diff = face_feat - fp_feat
        cos_sim = F.cosine_similarity(face_feat, fp_feat, dim=1, eps=1e-8).unsqueeze(1)
        pooled = (face_feat + fp_feat) / 2.0
        attn_input = torch.cat([pooled, diff, cos_sim], dim=1)
        logits = self.attention(attn_input) + self.logits_bias
        weights = F.softmax(logits, dim=1)
        concat = torch.stack([face_feat, fp_feat], dim=1)
        fused = (concat * weights.unsqueeze(-1)).sum(dim=1)
        return fused
```

核心思想：让模型根据**当前输入的两个人脸特征之间的相互关系**，自适应决定各自的权重。

MLP 的输入拼接了三路信号，共 513 维：
- **pooled**（256维）：两个模态特征的均值，编码两者的共同信息
- **diff**（256维）：两者之差，编码差异信息
- **cos_sim**（1维）：余弦相似度，编码整体一致性

这三路信号一起输入 MLP，MLP 输出两个 logit，加上 logits_bias（初始化为0），再 softmax 得到 [w_face, w_fp]。

**零初始化技巧**：MLP 输出层权重和偏置都初始化为 0，所以训练开始时 logits 全为 0，softmax 后权重正好是 [0.5, 0.5]。这样 MLP 可以从"平等对待两模态"这个基线出发，逐步学习何时该偏向哪个模态。

### 5.3 消融实验支持

```startLine:123:163:core/models/fusion_strategy.py
class AblationStrategy(FusionStrategy):
    def __init__(self, strategy: FusionStrategy, fusion_dim: int,
                 ablating_face: bool = False, ablating_fp: bool = False):
        super().__init__()
        self.strategy = strategy
        self.ablating_face = ablating_face
        self.ablating_fp = ablating_fp

    def forward(self, face_feat, fp_feat):
        if self.ablating_face:
            face_feat = torch.zeros_like(face_feat)
        if self.ablating_fp:
            fp_feat = torch.zeros_like(fp_feat)
        fused = self.strategy(face_feat, fp_feat)
        if self.ablating_face and self.ablating_fp:
            fused = torch.zeros_like(fused)
        return fused
```

通过 AblationStrategy 包装器，将指定模态的特征硬截断为零，实现单模态消融。这样可以公平对比：融合 vs 单用人脸 vs 单用指纹。

识别流程：接收图片 → FusionInferencer 提取特征 → Gallery 特征投影到融合空间 → MatchingService 多模态匹配 → 返回 Top-K 结果。

---

## 八、总结

本毕设的核心贡献是一条完整的**多模态融合识别技术链路**：

1. 人脸和指纹分别经过预训练的 ResNet50 + 注意力机制，提取 512 维 L2 归一化特征
2. 两路特征通过**恒等初始化的投影层**映射到 256 维融合空间
3. 融合策略支持简单加权和**注意力自适应融合**两种方式，后者根据两模态特征的相互关系动态调整权重
4. 训练阶段使用模态 Dropout、熵惩罚、标签平滑等正则化手段，防止模型偏向单一模态
5. 推理阶段统一经过融合模型，支持单模态缺失的鲁棒识别，Gallery 特征也投影到融合空间后进行匹配

相比单模态模型，融合模型在两个模态都可用时能实现更高的识别准确率和更强的抗干扰能力。
